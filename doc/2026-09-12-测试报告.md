## 4. 结论

1. core 守卫功能（timestamps 校验 / $pipeline 开关 / 反馈通道）与 1.0.0 多数据源定位在 Rust 单测、双端绑定测试中全部通过。
2. SQL 下推拒绝（pushdown unsupported）路径有专门用例覆盖，宿主层压测期间未出现静默错误结果。
3. core-node / core-py 产物与源码同步，双宿主集成链路健康。
